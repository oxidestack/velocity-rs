# Code of conduct

velocity-rs follows the [CNCF Code of Conduct](https://github.com/cncf/foundation/blob/main/code-of-conduct.md) in its
repository, its issues and pull requests, and wherever someone speaks for the project.

Report behaviour that breaks it privately to the maintainers, at <kustov.vitalik@gmail.com>: what happened, where and
when. The report stays confidential. The project has one maintainer today, so a report about that maintainer has
nobody else in the project to decide it; who decides it will be settled when there are more.
